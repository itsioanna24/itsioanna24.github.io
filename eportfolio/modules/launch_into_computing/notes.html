Unit 4 – Boolean Logic, SDLC, and Software Development Methodologies

Lecturecast Notes

Boolean Logic and Set Theory

  • Boolean logic: a system of algebra where values are reduced to true or false, represented as 1 or 0 in binary code.
  • Logical operators: AND, OR, NOT. Common gate types include AND, OR, NAND, NOR, and XOR — the foundation of all computer processors and memory storage devices.
  • Set theory is used in databases, AI, and programming. Operations such as union, intersection, and difference are used to manage and retrieve data efficiently.

Software Development Life Cycle (SDLC)

  • A structured, step-by-step process to ensure software is developed efficiently, meets user requirements, and maintains high quality.

Development Methodologies

MethodologyApproachBest For
WaterfallLinear and sequential; each phase completed before the next begins.Projects with clearly defined, stable requirements.
AgileIterative development in small increments ("sprints"); continuous feedback loop.Dynamic projects with changing requirements.
DevOpsIntegrates development and IT operations for continuous development, deployment, and monitoring.Environments requiring fast releases with stability and security.

Types of Software Testing

  • Unit Testing
  • Integration Testing
  • System Testing
  • User Acceptance Testing (UAT)
  • Performance and Security Testing
  • Quality Assurance

Types of Software Maintenance

  • Corrective — fixing bugs after deployment.
  • Adaptive — modifying software for a changed environment.
  • Perfective — adding new features or improving performance.
  • Preventive — proactive changes to prevent future issues.

Secure Software Development Best Practices

  • Secure Coding Standards: writing software that resists cyber threats.
  • Encryption and Data Protection: protecting sensitive user data.
  • Penetration Testing: simulating attacks to find vulnerabilities before deployment.

Unit 5 – Data Science, Databases, and AI Ethics

Lecturecast Notes

  • Data Science is an interdisciplinary field combining statistics, programming, and domain expertise to extract valuable insights from data.

SQL vs NoSQL

TypeStructureBest ForExamples
SQL (Relational) Strict schema; table-based format. Transactional applications: banking, finance, inventory management. MySQL, PostgreSQL, Microsoft SQL Server
NoSQL (Non-Relational) Flexible; unstructured or semi-structured data. Horizontal scaling. High scalability, real-time processing: social media, IoT, big data analytics. MongoDB, Cassandra, Redis

Data Analytics Types

  • Descriptive Analytics: summarises past trends.
  • Predictive Analytics: forecasts future outcomes.
  • Prescriptive Analytics: recommends actions based on data patterns.

Machine Learning Types

  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning

Ethical Challenges in AI

  • Bias in AI Models: AI can reinforce discrimination if trained on biased data.
  • Privacy & Data Security: AI must comply with regulations like GDPR.
  • Autonomous Systems: accountability questions when AI-powered systems cause harm.
  • Transparency in Decision-Making: AI models should be interpretable and fair.

Unit 8 – Cyber Threats, Defences, and Risk Management

Lecturecast Notes

  • Cybersecurity is the practice of protecting systems, networks, and data from unauthorised access, attacks, and damage.

Common Cyber Threats

ThreatDescription
MalwareViruses, worms, and ransomware designed to infiltrate and damage systems. Notable example: WannaCry (2017).
PhishingFraudulent emails appearing to come from legitimate sources, tricking users into revealing passwords or financial details.
DoS AttacksOverload a system with excessive traffic, making it unavailable to legitimate users.
Man-in-the-Middle (MitM)Attacker intercepts communication between two parties without their knowledge.
Zero-Day ExploitsAttacks exploiting unknown software vulnerabilities before developers can issue patches.

Defence Mechanisms

  • Firewalls: barrier between trusted internal networks and untrusted external sources; monitors and controls traffic based on security rules.
  • Encryption: converts sensitive information into unreadable code decryptable only with a secure key.
  • Antivirus / Endpoint Protection: scans files, monitors system behaviour, and blocks suspicious activity.
  • Multi-Factor Authentication (MFA): requires users to verify identity using multiple factors.
  • Intrusion Detection System (IDS): monitors network traffic for signs of suspicious activity.

Risk Management and Business Continuity

  • Risk management helps organisations identify, assess, and mitigate potential threats to IT infrastructure.
  • Disaster Recovery (DR) and business continuity planning ensure recovery from cybersecurity incidents, natural disasters, or system failures.
  • AI and ML are transforming cybersecurity through automated threat detection, real-time risk analysis, and faster incident response.

Unit 12 – Future Computing Trends and Emerging Technologies

Lecturecast Notes

  • Future computing trends are characterised by speed, complexity, and interconnectedness.
  • Edge computing moves data processing closer to the data source, reducing latency and bandwidth — particularly important in IoT applications requiring real-time decision-making.
  • AI in cybersecurity: enables anomaly detection, automated threat response, and predictive defence — but also empowers cybercriminals to create more sophisticated attacks including deepfakes and adaptive malware.

Key Future Technologies

TechnologyKey Points
Quantum Computing Promises massive processing power. Traditional encryption methods (RSA, ECC) are becoming vulnerable to algorithms like Shor's algorithm.
Post-Quantum Cryptography Quantum-safe approaches: lattice-based encryption, hash-based signatures, and code-based schemes. Essential for future-proofing data protection.
The Metaverse Convergence of AI, VR, AR, and blockchain into immersive digital worlds.
AI in Space Autonomous navigation, geological feature detection, and mission planning. Example: NASA's Perseverance rover. Challenges include radiation-hardened hardware and low-bandwidth environments.
AI and Robotics in Work Automating processes and enhancing productivity, but also displacing roles in manufacturing, customer service, and logistics.
Predictive Analytics Uses historical and real-time data combined with ML models for customer segmentation, demand forecasting, fraud detection, and risk management. Must be accompanied by ethical data practices and bias awareness.
